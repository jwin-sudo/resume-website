# Resume Website for Data Engineering Opportunities
This project is a React-based personal resume website designed to showcase skills, projects, and experience in data engineering to potential recruiters. It provides an interactive and professional platform for presenting career highlights, technical expertise, and achievements. The responsive design ensures seamless accessibility across devices, making it an ideal tool for networking and job applications.

Features

Clean, modern UI to highlight skills, experience, and certifications.
Interactive sections for showcasing data engineering projects.
Fully responsive design for desktop and mobile users.
Contact form for recruiters to easily get in touch.
Technologies Used

Frontend: React, CSS
Deployment: Github Pages

This project reflects the capabilities of a data engineer while offering recruiters an engaging way to evaluate skills and potential.
